# Layers animés — clairière

Toutes les images sont des PNG séparés, frame par frame, alignés sur le même canvas.

- `eau/f01.png` à `f08.png` : animation de l'eau du bassin.
- `lumiere_simple/f01.png` à `f08.png` : lumière forestière normale, à superposer séparément.
- `lumiere_evolution/f01.png` à `f08.png` : effet prismatique optionnel, uniquement pendant l'évolution.

Ordre de composition recommandé : base de la zone, eau, lumière simple, puis lumière évolution si l'événement est actif.
