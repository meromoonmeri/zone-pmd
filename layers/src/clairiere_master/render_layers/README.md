# Rendu PNG décomposé

Calques pleine résolution 1120 x 960, sans redimensionnement :
`sol.png`, `chemin.png`, `bassin.png`, `arbres.png`, `vegetation.png`.

`00_composite_reference.png` est la référence aplatie native. Les PNG RGBA sont
à utiliser comme calques image Tiled avec interpolation désactivée / nearest-neighbor.
Les pixels conservés proviennent directement de la référence native : aucun filtre,
rééchantillonnage ou compression destructive.
